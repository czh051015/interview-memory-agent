# OfferLoop —— 带长期记忆的面试陪练 Agent

> **一句话**：一个"记得你"的面试错题本——自动采集你的面试弱点，用遗忘曲线跟踪掌握度，面试前主动提醒，再用你的简历出结构化模拟面试、诊断你"面试为什么会崩"。

---

## 它解决什么真问题

应届生面完试，错题散在聊天记录里，**忘了就忘了**。OfferLoop 把面试复盘自动拆成结构化错题，跟踪每道题的掌握度，**在快忘的时候主动提醒**——而不是让你手动整理、自己记着去复习。

**别人回答"市场在考什么"，这个系统回答"你现在还差什么"。**

---

## 核心亮点

### 1. 动态记忆：不是静态题库，是会遗忘的记忆
每道错题带掌握度，按艾宾浩斯遗忘曲线衰减（`mastery × e^(-λt)`），复习答对回升（×1.5）、答错封顶（0.5）。双因子排序（相关性 + 重要性）让"最该复习的题"永远排第一，复习成果自动回流。

### 2. 主动性：面试前提醒，不是等你问
按遗忘状态分层（🔴快忘了 / 🟡该看看），只提醒 Top K 薄弱题，而不是无差别推全部。**"提醒"是系统主动给的，不是用户想起来才查的。**

### 3. 自动采集：越用越懂你
模拟面试中答差的新题，自动写回错题本（来源可追溯）；行为特征（答不到点 / 表达绕弯 / 回避问题）随面试累积，下次提醒自动带上。

### 4. 结构化面试官：不是错题抽查，是真面试
基于 **简历 + JD + 错题本 + 结构化方法论**（STAR / 宝洁八大问）出题，章节化流程（自我介绍 → 项目深挖 → 技术验证 → 行为面 → 动机面），带递进追问；结束后生成**复盘报告**，诊断"答非所问""简历与表现脱节"这类**单道题记不出来的系统性毛病**。

### 5. 多租户隔离
`--space` 一键开独立空间，试玩不污染正式记忆；每个空间独立的 Chroma collection + 文件目录。

---

## 技术栈

`Python 3.13` · `ChromaDB`（本地向量库）· `DeepSeek`（LLM）· `Ollama`（768 维中文嵌入）· `pydantic v2` · **纯函数状态机（无 LangGraph，刻意不套框架）**

---

## 可验证成果

- **183 个单元测试**覆盖记忆层全部纯函数：衰减边界、排序回流、状态机约束、幂等写回
- 检索阈值经 eval 脚本校准（Recall@5 稳定 + 噪音归零）
- **断点保护**：面试进行中崩溃，`--recover` 幂等补写，掌握度不重复涨
- 复盘报告真实诊断出「简历写得很好但面试讲不出来」的脱节问题

---

## 设计原则（一句）

> **LLM 只做语义活（拆解 / 出题 / 追问），衰减 / 排序 / 状态流转全是确定性纯函数**——数字可复现、可测试，不靠 LLM 编。

---

## 快速体验

```bash
python offerloop.py                 # 说人话：记错题 / 模拟面试 / 看提醒 / 看复盘
python offerloop.py --space 试玩     # 独立空间，试玩不污染正式
```
