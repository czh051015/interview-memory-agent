# 申论 Benchmark 采分点标注任务清单（卷级分发）

## 任务目标

把下面 8 套江苏申论卷，逐题标出「采分点 + 关键词」JSON，补进 benchmark。

当前已有 14 道（河南 11 + 江苏 3）。本批补 **约 25 道**（8 卷 × 非大作文题），重点补上「提出对策」与「应用文」两类缺口。


## 给标注 AI 的统一指令（复制给每个 AI，每 AI 处理一卷）

```

你是申论阅卷专家。我会给你一套卷的「完整给定材料 + 全部题干 + 全部参考答案原文」。请：

1. 先按"问题一/二/三/四"把题干与参考答案一一对应（答案区是连续编号，请按语义把答案归到正确题干）。

2. 大作文题（要求写 800/1000 字文章、给总论点）跳过，不标。

3. 其余每题输出一个独立 JSON 文件，schema 如下（id 用 {年份}{卷}_{题号}，如 2023B_3）：

{
  "id": "2023B_3",

  "meta": {"province":"江苏","year":2023,"type":"提出对策","vol":"B类","max_score":25},

  "task": "题干原文",
  "material": "本题相关给定材料原文（从整卷材料里截取对应部分即可）",

  "gold": {"reference_points": [

    {"id":"p1","point":"一个采分点的完整表述","keywords":["命中该点所需的关键词1","同义表述2"],"score":2},

    {"id":"p2", ...}
  ]},

  "samples": {

    "good": {"text":"把参考答案充实改写成的、能命中全部采分点的一篇作答","ratio":1.0},

    "bad":  {"text":"故意写偏的、只沾边不答点的跑题作答（专供验证 no_fool）","ratio":0.1}
  }
}

}

标注规则：

1. 一个采分点 = 参考答案自然断成的一条（①②③或段落），point 用完整话写。

2. keywords 给 2-4 个：别用大词（"发展/加强/完善"单独不算命中，需配语境）；覆盖同义（"政务公开"与"信息公开"都放）；抓具体动作/对象。

3. score 自行估算每点分值（总和≈max_score）。

4. good 作答要能命中 reference_points 里绝大多数点；bad 作答要明显跑题、几乎命中不了点。

5. 应用文题：把"格式分"（标题/称呼/落款）和"内容分"分开成不同采分点。

6. material 只需截取本题对应的给定资料，不必整卷照搬。

```
