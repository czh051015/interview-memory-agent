# 32 · 开发计划书：示证/诊断表述降级为「候选证据」（E2 文本比对 + 草稿化）

> 动机：用户拍板——把"错因/示范/分数"从**权威断言**降级为**候选证据**。  
> 核心原则：**传感器不撒谎，诊断不装懂**——漏点识别给事实，深度判断给候选，权威留给官方答案。

---

## 0. 一句话

**三处降级：① 错因从"LLM 因果推断"改成"确定性文本比对"（检测到 X，未检测到 Y/Z）；② 示范表述与改法加"草稿/以官方答案为准"声明；③ "最该补的漏点（分数）"去掉分数、改"候选未命中点"标记。**

## 1. 现状 vs 目标

| 当前设计（权威断言）                        | 目标设计（候选证据）                               | 改动层级                      |
| --------------------------------- | ---------------------------------------- | ------------------------- |
| "错因：你整段都在谈……未触及……"（LLM 因果推断，E0 级） | "文本比对：检测到 A，未检测到 B、C、D"（确定性事实比对，E2 级）    | **后端 guidance 改造** + 前端文案 |
| "示范表述：可表述为……正确写法"（隐含权威）           | "候选改写示例：一种可能的表述，供参考，以官方答案为准"（明确草稿）       | 前端文案 + **后端字段语义**         |
| "最该补的漏点（4 分）"（模型给分）               | "候选未命中点列表：以下点在你作答中未被识别，请自行对照官方答案复核"（无分数） | 前端文案 + leading 分数展示去掉     |

**关键洞察**：你要的"文本比对（检测到 A 未检测到 B/C/D）"**不需要 LLM**——它就是 keywords 与作答的确定性比对（`score.py` 阶段 1 已有 `any(kw in answer)` 的能力）。所以 L4 可以**从 LLM 因果推断改成确定性事实陈述**：0 token、可复现、不装懂。

## 3. 改动清单

### 3.1 后端：L4 错因 → 确定性文本比对（核心改动）

**改 `src/mock/prompts.py`**：删掉 LLM 版 CAUSE_PROMPT 的"错因诊断"职责（或保留给诊断层 Later），新增确定性函数。

**新增 `src/mock/runtime.py`（或 score.py 复用）**：`text_compare_cause(point, answer) -> str`

```
文本比对：检测到 {已命中词}，未检测到 {未命中关键词}。
例：文本比对：检测到「城际公交」，未检测到「高速免费、产业对接、人才协同」。
```

**实现**（复用 score 已有逻辑，0 LLM token）：

```python
def text_compare_cause(point, answer: str) -> str:
    hit_kw = [kw for kw in point.keywords if kw in answer]
    miss_kw = [kw for kw in point.keywords if kw not in answer]
    if hit_kw:
        return f"文本比对：检测到「{'、'.join(hit_kw)}」，未检测到「{'、'.join(miss_kw)}」。"
    return f"文本比对：未检测到任何得分关键词（{'、'.join(point.keywords)}）。"
```

**改动后 `GuidanceResult` 语义**：

- `cause_type`：从"完全没提/写偏/太模糊"改为**固定值 `"文本比对"`**（✅ 已拍板：保留字段，只换值）
- `cause`：从"LLM 错因说明"改为 **text_compare_cause 输出**
- `fix`：从"LLM 具体改法"改为**保留 + 前端标注"参考"**（✅ 已拍板，见 3.2）

> ✅ 决策点已拍板（2026-09-01 用户确认）：
>
> - **`cause_type` 保留**，值固定为 `"文本比对"`——错题本/前端数据结构零破坏，只换值（方案 A）
> - **`fix` 保留**，前端加"参考"声明——候选不是没有，是标注清楚不是权威

- `fix`：**保留**（LLM 生成的"具体改法"），前端加"供参考"声明——✅ 已拍板

> ✅ `fix` 决策已拍板（2026-09-01）：保留 + 前端"参考"声明——信息不丢，符合"候选草稿"定位

## 6. 决策记录（面试叙事）

> "示证模块最初用 LLM 做因果推断（'你是因为没理解 X 才漏的'）——但这是**装懂**：模型没有资格断言你的思维过程。我把它降级为**确定性文本比对**（'检测到 A，未检测到 B/C/D'，0 token、可复现），示范和改法标注'候选草稿、以官方答案为准'，分数去掉只留候选标记——**评分系统只给可验证的事实，不给不可验证的判断**。这和项目定位一致：传感器不撒谎。"
