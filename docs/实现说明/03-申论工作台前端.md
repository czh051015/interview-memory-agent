## 三、关键设计决策

1. **无状态练习会话**（20 §4.1）：服务端不存会话——前端持有 `question_id` + 累计 `rounds`（含 hit_ids/miss_ids/guided_point_ids 轨迹），每次 submit 全量重算；`complete` 由前端在「达标或轮次上限」时**显式调用一次**，避免重复回流。submit 响应额外返回 `hit_ids/miss_ids`（id 版，供前端累积轨迹；名称版仅供展示）。
2. **引导失败全链不 500**：start 的 `decide` 自带规则回退；submit 的 `_approach_guidance`（LLM）失败 → 规则降级提示「材料第 X 段有相关事例」（`_fallback_guidance`，只给位置不给关键词，与 `_APPROACH_PROMPT` 同语义）；complete 纯确定性不调 LLM。轮次上限（round=2）不再调 LLM，guidance 为空 → 前端判定 finished。
3. **录入 demo 版只预览不落库**（20 §3 与面试域 `/api/decompose` schema 不匹配）：新增 `/api/shenlun/record` 纯 API 壳版本，人审闸门（annotate_points）+ 正式入库仍在 CLI `scripts/run_decompose_question.py`，页面 notice 明示。
4. **首页即工作台**（20 §8 推荐采纳）：`/` → 申论工作台；面试 dashboard 迁 `/dashboard`，工作台 Sidebar 底部与 dashboard header 互链（面试域页面 `src/*` 与路由全部保留不动）。

## 七、引导原则修正（2026-08-30，伪引导 → 「位置 + 方向」）

**问题**：真实练习联调发现逼近引导是「伪引导」——LLM 的 hint 列举材料中的具体证据（「B县中医院骨科吸引A区患者」「GDP增幅差距缩小…1+1>2」），考生照抄 hint 即可命中关键词，引导替考生完成了「定位 + 识别」，等于喂答案。

**根因三重**：
1. prompt 自相矛盾：一边禁关键词一边示范「材料第4段有城际公交」（城际公交=设施互通关键词）→ LLM 学会「抄材料事例名词」模式；
2. benchmark 材料是单段连续文本（1544 字无换行）→ LLM 无位置编号可用，想指位置只能复述内容；
3. eval 两头漏：hint_grounded 测「有 ≥5 字材料子串」（重叠越多越易过）；no_spoiler 只防「答案独有内容」——转述/列举材料两头漏。

**新原则**：引导 = 「位置 + 方向」，禁止「内容列举」。材料在 user_prompt 中按句编号（`_segment_material`，[S1]…，>80 字长句按逗号再切），hint 唯一合法形态 = 「[S3] 句附近（讲{宽泛领域词}{领域/方面}）+ 元提问（想一想这对应哪个漏掉的点？）」；禁止专名/机构/具体事例/数字/关键词/同形短语直出；prompt 加正反例（用户实例做反例）。

**三条确定性红线**（`runtime._guidance_hint_ok`，运行时过滤 + eval 同口径共用）：
| 红线 | 判定 | 处置 |
|---|---|---|
| no_position | hint 必须含 `[S\d+]` 句号引用 | 断言 ==1.0 |
| no_overcopy | 与材料最长连续重叠 ≤ 8 字（DP） | 断言 ==1.0 |
| no_keyword_spoiler | hint 不含该漏点任一完整关键词（≥2 字） | 断言 ==1.0 |

LLM 服从不稳（前三轮 eval：2/6/0 违规波动）→ 红线不能只作断言：**运行时也过滤**，违规 hint 丢弃（`logging.warning`），全丢 → 调用方规则降级（`_fallback_guidance` 只给方向提示，不盲指句号——规则不知漏点对应哪句）。

**转述列举型伪引导**（「中医院骨科」「商贸」「农家乐」——确定性规则测不到）→ 走 judge 报告项 `evidence_spoiler` + 人工复核，**不转断言**；`copy_ratio`（hint 去停用字后 2 字滑窗属于材料的覆盖率）作转述型信号记录（伪引导 0.46 vs 合规 0.046）。

**验证（第 3 轮 guidance_eval，19 样本）**：product_pass 1.0（19/19，运行时过滤 0 条）、LLM 原始质量三条红线 1.0、旧红线 no_spoiler/no_fabrication/hint_grounded 1.0 不回归、copy_ratio mean 0.046、judge 4.0/5；`pytest tests/ -q` 304 passed（mock hint 同步新格式）；`run_evals --baseline` 重登（prompt 行为变更 → 旧锚点失效）。
