## 一、本阶段做了什么

按 [22-逼近引导实施方案](../22-逼近引导实施方案.md) 实现「考你 → 帮你」范式转变的后端部分：

- **L1 标红定位**（0 token，无 LLM）：`score_answer` 每个命中点带 `matched_text`（作答中命中关键词的句子片段，最长 100 字）；每个漏点挂 `material_source`（材料锚定：`材料第X段：'…'`，关键词与材料句子重叠度计算）；
- **L3 材料溯源**：与 L1 同源，由 score 动态计算，不另设 LLM 调用；
- **L2 示范表述**（LLM `DEMO_PROMPT`）+ **L4 错因诊断**（LLM `CAUSE_PROMPT`，cause_type 三类：完全没提/写偏/太模糊 + 改法）：新 `guidance(point_id)` 按需生成，一次一个漏点，失败不阻断（L3 仍返回）；
- **推 1 个最该补**（Q7b）：`pick_leading_point` 红档（weak_points miss≥2）优先，否则 score 最大（Q9a）；
- **错题本按漏点入库**（Q3）：每漏点一条 KnowledgeItem，稳定 id `sl_{question_id}_{point_id}`（upsert 幂等），初始 status=fail、reflow_tier=red；
- **API**：`practice/submit` 改 L1+推1 响应；新增 `practice/guidance`（按需示证）、`wrongbook`（按漏点入库，material_source 服务端重算保证可溯源）；
- **CLI**（§5）：`python -m src.shenlun.cli`——上传 → L1 → 推1+示证 → 交互 show/add/quit；
- **eval**（§6）：删除旧 guidance_eval（哲学不兼容），新写 demo_eval（三红线：material_anchored / no_full_answer / no_fabrication），run_evals SUITES 换轨。

删除：`_APPROACH_PROMPT`、旧逼问 runtime（practice_one / PracticeRound / 伪引导过滤器 / 进度持久化）、`src/mock/cli.py`、`src/mock/__main__.py`、旧 guidance_eval、旧逼问 CLI。

推迟：前端改造（docs/22 §7）、埋点（Q8 不做）。

## 三、关键设计决策

1. **L1 与 L3 同源（0 token）**：matched_text / material_source 全部由 score_answer 一次计算，不引入独立「溯源」流程——示证的可溯源是评分器的免费副产品，也是 eval 能确定性断言的根基。
2. **推 1 个而非推 N**（Q7b）：`pick_leading_point` 只返回一个最该补的漏点。错题本历史参与排序（红档优先），但 eval/CLI/API 用同一函数——red-tier 读 weak_points 走 lazy import 避免 import cycle。
3. **guidance 只服务一个 point_id**：LLM 只被点开时才调（CLI show / API 按需），submit 主路径 0 token；LLM 失败 demo/cause 置空但 L3 照常返回，示证永不阻断。
4. **错题本按漏点一条**（Q3）：不是整题一条。id 稳定 → upsert 幂等（重加不重复），reflow_tier 初始 red 供回流优先。
5. **wrongbook 端点服务端重算 material_source**：客户端传的可能造假，服务端用 score 重算，eval 红线 no_fabrication 也因此能在 API 层闭合。
6. **eval 三红线重新定义**（§6）：旧 guidance 红线的设计意图是「引导但不泄露」，与示证「直接给关键词/材料原话」哲学相反，不可复用；no_full_answer 用「与参考答案去停用字后 LCS ≥20 字且不在材料中」判定代写，材料引用放行。
7. **demo_eval 隔离默认 DB**：pick_leading_point 会读真实 weak_points 档案（红档优先是设计行为），本机开发期档案会污染「无档案→score 最大」的确定性分支 → eval 内把 reflow.DB_PATH 换到 tempfile（实测首跑 leading_ok=0.947，隔离后 1.0）。

- **anchored_coverage 0.687**：报告项，非红线。漏点锚不到材料原话 = 材料没直接覆盖该点（如应用文 3 个样本锚定 1/2），属材料与金标关系问题，不是实现缺陷；后续可考虑「未锚到降级显示」的产品处理；
