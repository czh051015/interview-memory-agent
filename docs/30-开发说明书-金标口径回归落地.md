## 1. 背景（29 结论）

- nosource 假阳性 100% 不是 LLM 能力问题，是**金标口径错位**：把"质量评分（深度不足）"塞进了"漏点识别传感器"
- 真实阅卷"踩点给分、多写不扣分"——考生写到核心词就得分
- 解法：金标按"漏点识别"口径重标（**提到核心内容 = 该给分；只有完全没提 / 答非所问 = miss**）；深度不足降级为诊断层标注（cause=套话无具体性）

## 2. 改动清单

### 2.1 金标重标（核心，改 3 个文件）

**重标规则（29 §3.1，唯一权威口径）**：
```
作答提到该点核心内容（核心词/同义改写）→ 该给分（expected_hit_ids 含该点）
只有"完全没提"或"答非所问（方向与题干要求不符）"→ miss
"深度不足/套话"不再作为判 0 理由（降级为诊断标注）
```

**金标规则 v1.1（2026-09-01 人工复核锁定）**：
```
边界澄清：答非所问（按题干指令，作答写成另一种题型，如要求概括却写建议）
           → 全集空，无论作答里是否撞上核心词。
           （实测依据：city_1 nosource1 含"城际公交/产业对接"核心词
            但仍判全 0——方向错整卷作废，不逐点找分）
复核锁定：jiangsu nosource1 全给 c1-c4 ✅（用户确认）
          city_1 nosource1 全 0 ✅（用户确认，答非所问）
          city_3 nosource1 给 c1 ✅（用户确认，"市集潜力巨大"撞 kw"转型的潜力"）
```

**逐条明细（直接照抄到文件）**：

**① `benchmark/medium/jiangsu_2022_b_3.json`**（对策题·方向词罗列·方向对）
```json
"expected_hit_ids": ["c1", "c2", "c3", "c4"]
```
理由：题干就是"提出建议"，方向对；四条分别提到"科学设计直播方案/现场实验·主播连麦/组建团队·民警代言人/多平台联动·热门主题"——核心内容都在，按漏点识别口径"没漏"→ 给分。深度不足（只有骨架）降级为诊断，不判 0。
✅ 复核点已确认（2026-09-01 用户拍板：全给 c1-c4）。

**② `benchmark/medium/henan_2025_city_1.json`**（概括题·写成建议·答非所问）
```json
"expected_hit_ids": []
```
理由：题干要求"梳理概括举措和成效"，考生写成"建议两地应加强……"——**方向不符（答非所问）**，按规则全 miss（保持不变）。
✅ 复核点已确认（2026-09-01 用户拍板：继续全 0，答非所问口径）。注：作答里实际撞上了"城际公交/产业对接"核心词——这正是 v1.1 边界澄清"答非所问覆盖核心词撞车"的实测依据。

**③ `benchmark/medium/henan_2025_city_3.json`**（综合分析·方向词罗列·方向对）
```json
"expected_hit_ids": ["c1", "c2", "c3", "c4", "c6"]
```
理由：c2（互动体验/情感社交）、c3（文化景观/城市吸引力）、c4（创业平台/带动就业）、c6（品牌化/差异化/避免同质）均提到核心 → 给分；c5（特色策划/业态融合/可持续）作答完全没提 → miss。
✅ 复核点已确认（2026-09-01 用户拍板：给 c1——作答原文"'可能性'指市集潜力巨大"直接撞 c1 关键词"转型的潜力"，算总起定位已到位）。
