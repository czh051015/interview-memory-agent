# 29 · 金标口径回归：nosource 从"死磕目标"到"诊断层素材"

> 配套 docs/26-28。28 号判据强化生效后（jiangsu nosource1 4/4 HIT → 2 HIT + 2 MISS），
> 剩余命中点经核查**判得合理**——本文是今天最值钱的产品判断：**nosource 假阳性 100% 不是 LLM 能力问题，
> 是评测目标错位（把"质量评分"塞进了"漏点识别传感器"）+ 指标口径过粗（样本级非点级）。**

---

## 0. 一句话

**回到 08-28 的产品定位（评分=漏点识别传感器，不追求精确）**：考生"提到该点核心内容"= 没漏 = 判 hit 合理；"深度不足/套话"是诊断层（L4 cause）的活，不该由传感器判。**解法 = 重标金标口径 + 指标改点级，不是再调一轮 LLM prompt。**

## 1. 为什么（攻防史 + 数据实证）

### 1.1 历程回顾（为什么我们走偏了）

| 阶段 | 动作 | 结果 |
|---|---|---|
| v0 | nosource 样本造出来，人工金标判 0 | 假阳性 100%（A/B 引擎都是） |
| v1 | CoT 三步（材料支撑=判定钥匙） | 还是 100%——LLM 找到真实材料句（方向词本就从材料抄的） |
| v2 | 判据 3 强化（与 point 定义完整度对比） | **生效**：jiangsu 4/4 HIT → 2 HIT + 2 MISS（c1/c3 被"套话无具体性"拦住） |

### 1.2 关键数据：剩余的命中点其实判得对

v2 后 jiangsu nosource1 剩余 2 个 HIT：
- c2"创新直播方式"——作答"采用现场实验、主播连麦等创新方式"——**确有具体做法**（现场实验/主播连麦是具体方式）→ hit 合理
- c4"扩大覆盖面"——作答"多平台联动、选热门主题"——**有具体做法** → hit 合理

henan city_1 nosource1 剩余 4 个 HIT（c1/c2/c4/c5）——作答"加强城际公交建设""培育新兴产业""深化人才协同""促进灵活就业"——**都提到了该点的核心词** → 按"踩点给分"阅卷规则，阅卷人会给分。

**结论：人工金标判 0 是"深度加严"，超出传感器职责；LLM 判 hit 反而符合真实阅卷与产品定位。**

## 2. 核心判断：传感器 vs 诊断层的职责边界

```
评分层（传感器，08-28 定位）          诊断层（L4 cause，已有）
─────────────────────────            ─────────────────────────
考生答没答到这个点（漏点识别）          答得质量如何（为什么丢分）
"提到城际公交" → hit ✅               "但只有骨架没有血肉" → cause=套话无具体性 ✅
"完全没提" → miss ✅                  "写成建议偏题" → cause=答非所问 ✅
```

**把"深度不足"判成 miss = 用传感器做诊断层的活**——结果就是三个小时死磕 LLM 学"深度判断"（它本就不该会，因为阅卷踩点制也不这么判）。

**评分判 hit + 诊断标注"套话无具体性"，两全其美**：考生看到"这个点你提到了，但只有骨架"，复习价值反而更高。

## 3. 解法（三件事，都是目标修正不是代码死磕）

### 3.1 重标 nosource 金标（漏点识别口径）

`benchmark/medium/*.json` 的 `expected_hit_ids` 重标规则：
```
作答提到该点核心内容（核心词/同义改写）→ 该给分（expected_hit_ids 含该点）
只有"完全没提"或"答非所问（方向与题干要求不符）"→ miss
"深度不足/套话"不再作为判 0 的理由（降级为诊断标注）
```

影响样本：jiangsu nosource1（4 点 → c2/c4 给分）、city_1 nosource1（c1/c2/c4/c5 给分）、city_3 nosource1（待按规则重标）。

### 3.2 指标改点级

`nosource_fp_rate` 从"样本级"（3/3 样本有误判=100%）改"点级"（误判点/总点）：
```
样本级（现在的）：任何样本有误判点 = 假阳性 → 掩盖"点级已在降"
点级（改后）：jiangsu 50%（4 点错 2）、city_1 44%（9 点错 4）——真实水平
```

### 3.3 LLM 卸下"深度判断"的锅

- prompt 判据 3（套话无具体性）**保留**——但它的角色从"决定 hit/miss"降级为"hit 的同时输出诊断标注"（cause=套话无具体性，供前端/错题本用）
- 或：判定保持 hit，cause 字段承载"套话无具体性"提示——**评分层和诊断层解耦**
