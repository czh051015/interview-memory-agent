# Benchmark Pilot 拆解方法论 + 第一道 Item 记录

> 本目录是 `docs/13-申论Agent系统设计` 里定的 **benchmark 数据集** 的第一道 pilot item。
> 目标：把公开阅卷规则加工成**机器可读、可验证**的采分点金标，为"客观踩点评分引擎"提供地基。

## 一、你拿到一份材料后，"再怎么做"（输入 → 输出）

### 输入（一份可标注的素材长这样）
- 题干（含分值、要求）
- 标准答案 / 参考答案（采分点的**载体**）
- 阅卷规则 / 赋分标准（怎么给分）
- 真实样卷 + 点评（验证你拆的采分点能不能复现人工分——**这是金标准**）

### 输出（结构化 JSON，schema 见 `slb_w_huatu_001.json`）
- `reference_points`: 内容采分点数组，每个 `{id, layer, point, keywords[], score}`
  - `point` = 一个得分意思；`keywords` = 命中该点所需的任一关键词/关键表述；`score` = 该点分值
- `format_checklist`: 格式要素清单（应用文特有，小题可无），每个 `{element, hint, weight}`
- `scoring_criteria`: 原始阅卷规则原文 + 我们的拆解说明
- `approved / approved_by`: **人类审核闸门**——进正式 benchmark 前必须人审通过（防"LLM 标 LLM 判"循环论证）

### 拆解规则（3 条铁律）
1. **采分点从材料/标准答案来，不拍脑袋**。本题 material 未公开，采分点从"标准答案"反推（标准答案本身依据材料提炼，属 acceptable proxy）；理想应 material-grounded，补 material 后重核。
2. **应用文是分档制，不是纯踩点** → 必须拆成**两套**：`reference_points`（内容可踩点）+ `format_checklist`（格式要素）。否则无法 benchmark。
3. **分值可加总但要标注"分档制非简单求和"**：content_hit_ratio 与 format_complete 共同决定档位，不能只靠踩点求和给分。

## 二、本题（slb_w_huatu_001）拆解对照阅卷规则

| 阅卷规则原话 | 我们的结构化落地 |
|---|---|
| 条件(1) 逻辑结构：标题—背景—汇报内容—总结 | `format_checklist` 4 要素（标题/背景/三层面/总结）|
| 条件(2) 信息量大、内容全面、紧扣资料 | `reference_points` 12 个内容点（c1-c12，分三个层面）|
| 条件(3) 语言流畅朴实 | 评分引擎的语言维度（Next，不在 A 模式）|
| 样卷一点评：缺"制定规划""服务提供商" | c1、c8 作为独立点，正对应这两个缺失项 |
| 一类14-20基准16 / 二类7-14 / 三类7以下 | 内容16 + 格式4 = 20，档位由命中率+格式完整度映射 |

## 三、验证结果（跑 `score_match.py`，模式 A 纯关键词）

| 样卷 | 人工 | 内容 recall | 格式 | 预测档位 | 复现 |
|---|---|---|---|---|---|
| s1 | 6分/三类 | 0.19 | 0/4 | 三类 | ✓ |
| s2 | 15分/一类 | 0.94 | 4/4 | 一类 | ✓ |

**结论**：结构化采分点能复现人工阅卷档位。这证明"公开阅卷规则 → 人工结构化 → 确定性踩点匹配"这条路通。

## 四、A 模式暴露的漏判（这正是 B/C/D 消融的动机）

纯关键词子串匹配对**拆分/同义表述**漏判明显：
- s1 把"机器人产业学院…工业小镇"写成，未含连续"机器人小镇" → c4 漏
- s1 写"政府发挥有为之手…互动"，未含"辅助生态" → c9 漏
- s1 写"机器人换人"，未含"机器换人" → c6 漏

→ 零散关键词作答会被 A 模式低估内容分（但档位仍对，因格式也缺）。**B(LLM模糊)/C(embedding语义)/D(混合+Rerank) 就是补这块**，后续用消融量化 `D−A` 增量。
